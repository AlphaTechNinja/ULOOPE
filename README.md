# ULOOPE
(Untitled Lua Object Oriented Programming Engine) this is a small engine that aims to be pure Lua but exposes a lot of object oriented features and a simple game engine model

## Class System
If you are looking for documentation on the class system please look at the <a href="https://github.com/AlphaTechNinja/ULOOPE/blob/main/%20classes.lua">classes.lua</a> file as it has the most documentation on it.
